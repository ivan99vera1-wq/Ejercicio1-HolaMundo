## 📖 Descripción

Este es el **Ejercicio 1** de mi serie de práctica en Java. Es el clásico
**"Hola Mundo"**: el punto de partida de todo programador. El programa imprime
dos líneas de texto en la consola, demostrando la estructura mínima de una
clase Java y el uso de `System.out.println()`.

> 🎯 **Objetivo del ejercicio:** entender la estructura básica de un programa
> Java (`clase` + `método main`) y mostrar texto por consola.

## ✨ Qué hace

```
Hola , Me llamo Ivan
Estoy aprendiendo Java
```

## 🧠 Conceptos practicados

| Concepto | Descripción |
|:--|:--|
| `public class` | Declaración de una clase pública |
| `public static void main` | Método de entrada de todo programa Java |
| `System.out.println()` | Impresión de texto en consola |

## 🛠️ Requisitos

- **JDK 8** o superior ([Descargar JDK](https://adoptium.net/))
- Un editor: IntelliJ IDEA, VS Code o similar
- Terminal o símbolo del sistema

## ▶️ Cómo ejecutarlo

```bash
# 1. Compilar
javac src/Main.java

# 2. Ejecutar
java -cp src Main
```

O directamente desde **IntelliJ IDEA** → botón ▶ *Run*.
